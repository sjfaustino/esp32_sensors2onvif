Install the sensors2onvif hub

Puts the hub's firmware, release RELEASE, on a blank board over its USB cable, from this page. Later updates go on from the hub's own page, under System > Maintenance.

This browser cannot reach a USB board. Use Chrome or Edge on a computer.

1. Plug the board in, and choose it

ESP32-S3 with 16 MB of flash and 8 MB of PSRAMN16R8: moving pictures, up to 20 frames
ESP32 with 16 MB of flashStill pictures
ESP32 with 4 MB of flashStill pictures, and a shorter event history

The browser asks which port: choose the board's. Installing erases the whole board, so use this for a new hub; a hub already running keeps its settings only when updated from its own page.

2. Set it up

  1. Once it has restarted, press the board's BOOT button. A new hub has no password yet, so it opens its setup network only after that, for 15 minutes: a Wi-Fi network called esp-alarmhub-setup. Join it from a phone or a computer.
  2. The page that opens asks for the hub password, 8 to 63 characters that only you know; the NVR will need it too.
  3. Choose your Wi-Fi network. The hub joins it, and its page tells you what to do next, one step at a time.

Checking the files

The files on this page are copied from the release, checked against its SHA256SUMS first. Each was built by the repository's release workflow from the tagged commit, which gh attestation verify <file> --repo sjfaustino/esp32_sensors2onvif confirms.
