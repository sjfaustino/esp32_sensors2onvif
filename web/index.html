Notifications

The hub can send each alert to a web address on your network, such as a Home Assistant webhook, Node-RED or a self-hosted ntfy server. Use http:// and an IP address; https and names are not supported.

Backup and restore

The backup file holds the WiFi and hub passwords in plain text, so keep it somewhere safe. Pictures are not included.

Download backup

Full backup

The settings, every picture, and each sensor's name and alert settings, in one file made by this browser. Restoring adds the sensors and pictures in it, replacing any with the same name, then replaces the settings and restarts the hub.

Reset settings

Erases the saved WiFi networks, ports, name, web password, fixed address, time and notification settings. Pictures, sensor nodes, and the ESP-NOW key and token that sensors use, are kept.

Time

The NVR always receives UTC, so these settings only change the time shown here and the scheduled restart. After a power cut, a manual time is read once from the NTP server if the hub can reach it; otherwise set it again.
